# 默认阅读书籍

把书籍放入 `public/default-read/`，阅读模块会自动将它们加入书架，无需手写书单或修改页面代码。

支持 `.md`、`.markdown`、`.txt`、`.text`、`.epub`，扩展名不区分大小写；支持任意层级的子文件夹，一份文本或 EPUB 对应一本书。图片等附件不会单独出现在书架中。

例如：

```text
public/default-read/
  一本小说.txt
  另一本书.epub
  图文故事/
    图文故事.md
    cover.jpg
    images/
      illustration.jpg
```

Markdown 中的图片相对当前 MD 文件定位：`![](images/illustration.jpg)`。现有文档使用的 Windows 反斜杠路径也能识别。支持标题、段落、引用、列表、代码、粗体与链接；原始 HTML 作为文字显示。文章有小节标题时按标题生成目录，没有时按篇幅自动分节。

书名优先使用 Markdown 开头的一级标题，作者识别 `作者：名字`（也支持放在引用段落中）。TXT 使用文件名，EPUB 使用其书籍元数据。可在书籍同目录放置与文件同名的图片，或 `cover.jpg`、`封面.png` 等作为封面；没有封面时显示文字封面。

开发服务器会监听目录变化，新增、修改或移除文件后刷新页面。静态发布的书单在站点构建时自动生成，新增书籍后随下一次站点发布生效。文本与附件保持在原来的公开路径中，不会内联到 JavaScript 包。

默认书籍使用稳定 ID，刷新页面不会重复导入。正文变化后会更新缓存，保留已记录的阅读章节与进度；从目录移除的默认书籍会在下一次访问书架时移除缓存，不影响手动导入的书籍。手动导入单个 Markdown 文件时，浏览器无法读取同目录的图片；有本地配图的文章建议放入上述默认目录。
