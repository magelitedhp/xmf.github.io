# v0.1.9 · 数独加入游戏厅

- 日期：2026-10-14
- 版本：0.1.9
- 对比基线：`48089b1`（v0.1.8 发布提交）
- 发布目录：`docs/`（GitHub Pages），保留 `CNAME` 自定义域名配置和 `music-api.md`。

新增第五款浏览器游戏《数独》，参考 TheSudoku.com 的在线数独体验，围绕 Yumo 现有玻璃质感重新设计棋盘、操作面板和响应式布局。题目生成、唯一解校验、交互逻辑与视觉均为独立实现。本记录覆盖基线之后的源码、SVG 封面、站点构建产物与文档改动。

## 唯一解题目与五档难度

- 新增简单、中等、较难、专家和极限五档难度，分别以 45、39、33、29、25 条线索为目标生成题目。
- 使用随机化完整终盘、中心对称挖空和回溯求解计数生成题面；每次移除线索后验证解数量，确保最终题目只有一个解。
- 提供难度切换、新游戏、重新开始、完成度、用时、错误次数及分难度最佳时间。
- 当前未完成题目、候选笔记、错误、提示次数和计时状态自动保存在浏览器本地，重新进入页面后可继续。

## 完整解题交互

- 支持数字输入、候选笔记、撤销、擦除、提示、暂停、完成结算和再次挑战。
- 选中格会联动高亮同行、同列、同宫与相同数字；正确填写后自动清理相关格子的同数字候选笔记。
- 错误数字使用独立颜色与轻微反馈动画，不会阻止玩家继续修改；提示可填入当前格，也可自动寻找下一处未完成位置。
- 数字面板显示各数字剩余数量，某个数字完整出现九次后自动禁用。

## 操作、动画与可访问性

- 桌面端支持方向键、数字键、`N` 笔记、`H` 提示、`Backspace` / `Delete` 擦除、`Ctrl+Z` 撤销及 `Esc` / `P` 暂停。
- 快捷键同时识别字符值与 `KeyN`、`KeyH`、`KeyP`、`KeyZ` 物理键位，改善中文输入法和不同浏览器下的兼容性。
- 修复格子自身描边与浏览器焦点框叠加造成的“双框”；改为单一选中游标，并在格子间使用约 200 ms 缓动过渡。
- 同行、同列与同宫底色同步淡入淡出；为减少动态效果的系统设置保留无动画分支。
- 棋盘采用网格语义、逐格描述、选中状态和漫游式 `tabindex`，触屏按钮与键盘焦点共用同一选择状态。

## 游戏厅与视觉

- 将《数独》接入 `/games` 和 `/games/sudoku`，新增“益智”筛选、游戏简介、操作说明、开发说明与参考来源。
- 新增蓝白数独 SVG 封面和专属游戏外壳配色；桌面端采用棋盘与操作面板双栏布局，窄屏下改为紧凑横向数字键盘。
- 支持游戏厅统一全屏外壳；390 px 手机视口下棋盘、数字键盘与工具按钮可在单列内完整操作。
- 更新根 README 的功能、游戏列表和目录结构，并归档本版本更新记录。

## 验证与发布

- Vue / TypeScript 类型检查与 Vite 生产构建通过，共转换 113 个模块。
- 浏览器实测五档难度分别生成 45、39、33、29、25 个给定数字；极限难度单题生成约 0.3 秒。
- 笔记、撤销、提示、错误计数、难度筛选和本地断点恢复通过；桌面与 390 px 手机布局检查无控制台错误。
- 最终快捷键兼容与选中游标改动通过类型检查、生产构建及构建产物关键字核对。
- 重新构建并同步站点资源到 `docs/`，核对入口脚本、数独脚本与样式文件和 `dist/` 一致，同时保留 GitHub Pages 域名与文档文件。
