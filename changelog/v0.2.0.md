# v0.2.0 · Yumo 阅读与灵感工作台扩展

- 日期：2026-10-16
- 版本：0.2.0
- 对比基线：`78233d0`（v0.1.9 发布提交）
- 发布目录：`docs/`（GitHub Pages），保留 `CNAME` 自定义域名配置、`music-api.md` 与 `reader-sources.md`。

新增「Yumo 阅读」模块，并把灵感工作台从三项工具扩展为九项。阅读模块完全运行在浏览器中：本地导入 TXT / EPUB、连接自定义书源在线搜书、解析分层目录并阅读正文，书籍数据与阅读进度保存在 IndexedDB。本记录覆盖基线之后的源码、样式、文档与站点构建产物。

## Yumo 阅读模块

- 新增 `/read` 书架、`/read/book/:id` 书籍详情与 `/read/book/:id/chapter/:chapter` 沉浸式阅读器三条路由，顶栏导航加入「阅读」入口。
- 书架以卡片展示封面、格式标签、章节数与阅读进度，并可直接继续阅读；首次进入会自动放入一本内置《Yumo 阅读指南》。
- 书籍详情页展示封面、作者、简介、章节数、字数与进度统计，目录按每 50 章分组，并支持按章节名筛选。
- 阅读器提供目录侧栏、上一章 / 下一章、左右方向键翻章，以及字号、行距、版心宽度与纸张 / 护眼 / 夜间三套主题。
- 当前章节与滚动位置、阅读设置都会自动保存，重新打开页面后回到上次停下的位置。

## 本地导入与导出

- 支持 TXT 导入：默认自动识别 UTF-8，失败时回退 GB18030，也可手动指定 UTF-8 / GB18030 / Big5。
- TXT 按「第×章 / 回 / 节 / 卷 / 集 / 部 / 篇」等标题切分章节，缺少标题时按约 9000 字分节。
- 支持 EPUB 导入：读取 `META-INF/container.xml` 与 OPF 清单，按 spine 顺序提取章节、书名、作者、简介与封面图。
- 单个文件限制 80 MB；书籍、章节与阅读进度写入 IndexedDB，书源与阅读设置写入 LocalStorage。
- 书架内容可导出为带 BOM 的 UTF-8 TXT，或使用 JSZip 生成 EPUB 3（含 nav 目录与样式表）。

## 书源引擎

- 书源沿用 so-novel 的搜索 / 详情 / 目录 / 正文四段结构，支持 CSS Selector 与 XPath（以 `/` 或 `xpath:` 开头）；出于安全考虑不执行书源中的 JavaScript。
- 选择器默认取文本，`@href`、`@src`、`@content`、`@value`、`@text` 可读取属性；搜索地址与 POST 请求体支持 `%s`、`{keyword}`、`{{keyword}}` 占位符。
- 详情页与目录页分离时，`toc.url` 支持 `%s`，并可取 `book.url` 正则的首个捕获组作为书籍 ID；详情解析回退到 `og:novel:*` 元信息。
- 正文支持 `filterTag` 剔除广告节点与 `filterTxt` 正则过滤；在线章节按需加载并缓存，已读内容可离线再次打开。
- 内置 11 条复制自 [freeok/so-novel](https://github.com/freeok/so-novel) `bundle/rules/main.json` 的默认书源，可一键导入而不依赖 GitHub 网络；也支持粘贴 JSON 或从远程地址导入。
- 书源可配置 `corsProxy`（简单前缀或含 `{{url}}` 的模板）以应对跨域限制，界面明确提示静态站点无法绕过源站策略。
- 新增 `docs/reader-sources.md`，说明书源字段、导入方式、代理配置与本地数据边界。

## 灵感工作台扩展

- 工具从 JSON / Base64 / 配色三项扩展到九项，新增 URL 编解码与参数解析、时间戳转换、文本处理、图片压缩与格式转换、二维码生成和文本差异对比。
- 工作台改为侧栏分类布局：桌面端使用左侧固定工具导航，窄屏自动切换为三列 / 两列目录，每项工具带独立标题与说明。
- 新增 `jszip`、`qrcode` 运行依赖与 `@types/qrcode` 类型声明；输入内容与文件仍只在当前浏览器处理。

## 站点与导航

- 顶栏与首页入口加入「阅读」，首页入口卡由四张扩展为五张，并新增书本造型的入口插画与配色。
- 阅读器章节页隐藏整站页脚，避免打断沉浸阅读；阅读模块使用独立的 `reader.css` 样式。
- 更新根 README 的功能说明、目录结构与版本信息。
