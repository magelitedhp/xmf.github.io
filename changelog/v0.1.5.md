# v0.1.5 · 游戏厅

- 日期：2026-10-09
- 版本：0.1.5

新增第五个功能模块「游戏」，以注册表封装游戏列表，首批上线两款浏览器原创小游戏。

## 游戏厅

- 新增 `/games` 列表页（封面 + 名称）与 `/games/:slug` 详情页（操作说明、致谢、全屏）。
- 游戏集中在 `src/modules/game/`，新增游戏只需写组件、放封面、在 `data/games.ts` 追加一条记录。
- 顶栏与首页项目区增加「游戏」入口。

## 《烬灯行》

- Canvas 像素横版动作肉鸽：十层长夜、两名首领、三段连击、冲刺无敌、每层三选一强化。
- 支持键盘、鼠标与触屏，音效由 WebAudio 合成。
- 玩法风格致敬 [熵刃 ENTROPY BLADE](https://game.inc.re/entropy-blade/)，代码与美术为原创。

## 《花园保卫战》

- 草坪塔防：15 种植物、10 种僵尸、12 关冒险（含坚果保龄球、传送带关）、保龄球挑战与无尽生存，带图鉴、设置与本地存档。
- 独立源码 `games-src/garden-guard/`，`npm run game:garden` 编译为约 120 KB 的单文件 HTML，构建中间产物一并保留。
- 站内以 iframe 嵌入，可新窗口打开。
- 玩法致敬 PopCap《植物大战僵尸》，非官方同人，美术、代码与音乐均为原创。

## 音乐

- 移除界面与页脚中的 GD音乐台 来源标注。
