# v0.1.8 · 超级玛丽加入游戏厅

- 日期：2026-10-10
- 版本：0.1.8
- 对比基线：`5c8d6d8`（v0.1.7 发布提交）
- 发布目录：`docs/`（GitHub Pages），保留 `CNAME` 自定义域名配置和 `music-api.md`。

新增《超级玛丽 · 蘑菇王国冒险》，将四个世界的像素平台游戏接入游戏厅。游戏代码、关卡、像素画面与合成配乐均在项目内实现。本记录覆盖基线之后的源码、静态资源、构建产物及文档改动。

## 四个世界与平台玩法

- 新增青风草原、萤石地底、云上群岛和余烬城堡，包含高低地形、移动平台、隐藏金币密室、检查点、十二枚星章、城堡守卫及公主救援。
- 实现固定步长物理、加速与制动、可变跳高、冲刺、离地宽容和落地输入缓冲；踩怪时长按跳跃可弹得更高。
- 增加顶问号砖、变大后碎砖、金币、成长蘑菇、火焰花、无敌星星与绿蘑菇；每累计 100 枚金币奖励一条生命。
- 实现踩怪、乌龟变壳与踢壳攻击、弹跳火球、食人花和首领战；受击后缩小并短暂无敌，失败后可从检查点继续。
- 提供标题、操作说明、世界选择、关卡介绍、暂停、结算、失败重试及通关结尾；已解锁世界、通关星章、最高分与声音偏好保存到本地浏览器。

## 画面、声音与操作

- 使用可编辑的像素矩阵和 Canvas 绘制角色、地形、动态金币与粒子，搭配草原、洞窟、云层和城堡的视差背景。
- 用 WebAudio 合成音效与配乐；最终 HTML 不加载外部图片、字体、脚本或音频。
- 同时支持键盘和多指触屏；触屏按钮独立位于画面下方，窗口失去焦点或页面进入后台时自动暂停。
- iframe 按内容高度自适应，全屏及独立打开时按可用高度缩放；修正内嵌滚动条、窄屏标题按钮以及横屏全屏时标题布局的问题。

## 游戏厅与单文件构建

- 将《超级玛丽》置于游戏厅列表首位，加入动作筛选及 `/games/super-mario` 详情页，提供全屏、新窗口打开与单 HTML 下载入口。
- 游戏厅数量文案改为读取实际条目数量；增加游戏外壳配色、操作介绍与本地 SVG 封面。
- 新增 `npm run game:mario` 和 `npm run game:mario:watch`，复用像素角色数据自动生成 SVG 封面。
- 最终 HTML 位于 `games-src/super-mario/output/super-mario.html`，约 64 KB；同一内容同步到 `public/games/super-mario/index.html` 和站点构建目录。
- 完整保留 TypeScript 源码、HTML 模板、像素源数据、调试 bundle、sourcemap、压缩文件、构建元数据、封面生成工具、测试脚本、截图与 JSON 验证报告。

## 文档与发布

- 更新根 README 的游戏列表、目录结构和构建命令；新增游戏 README，说明玩法、离线使用、源码结构及验证方法。
