# v0.1.0 · 夜航电台

- 日期：2026-09-08
- 版本：0.1.0

本次将播放器从静态原型推进到可联调、可发版的在线播放体验，并统一为 Nocturne 夜航玻璃拟态。

## 曲库联调

- 按 `docs/music-api.md` 接入 [GD音乐台](https://music.gdstudio.xyz) 接口，默认稳定源 `netease`。
- 发现页自动检索热门曲目；顶部搜索走 `types=search`，支持歌曲、艺人、专辑。
- 点击播放后请求 `types=url`，用真实音频播放，不再用定时器假推进度。
- 封面走 `types=pic`，歌词走 `types=lyric`，正在播放页会滚动高亮当前 LRC。
- 收藏与最近播放写入本地；封面、播放地址和歌词带缓存，降低 5 分钟 50 次的频率限制压力。
- 开发环境通过 Vite 代理 `/gdstudio-api` 访问接口，生产环境直连官方 API。

## 界面

- 视觉从 macOS 浅色原型改为夜航玻璃拟态：深墨夜景底 `#0B1322`、月光/钢蓝/香槟光斑、无色玻璃面板。
- 香槟金 `#E4B863` 只用于主播放按钮、进度手柄和关键数字。
- 发现、搜索、收藏、正在播放四个主视图以及底部播放栏全部按同一套玻璃材质与弹簧缓动更新。
- 正在播放页保留黑胶封面，歌词区独立滚动并对齐当前句。

## 发版说明

- 生产构建输出到 `docs/`，沿用本仓库 GitHub Pages 的打包方式。
- 曲库来源需注明：GD音乐台 (music.gdstudio.xyz)。部分曲目可能因版权没有播放地址。
