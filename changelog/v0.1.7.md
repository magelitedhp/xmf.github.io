# v0.1.7 · 花园保卫战角色美术

- 日期：2026-10-10
- 版本：0.1.7
- 对比基线：`ce7b2ca`（v0.1.6 发布提交）
- 发布目录：`docs/`（GitHub Pages），保留 `CNAME` 自定义域名配置和 `music-api.md`。

本版本整理 v0.1.6 之后《花园保卫战》的源码、角色美术、封面生成工具与构建产物改动。

## 角色与战斗画面

- 参考经典版角色造型，以 Canvas 2D 矢量重绘 15 种植物、3 种保龄坚果和 10 种僵尸，统一轮廓、描边、配色与明暗，补充植物叶片、花瓣、嘴形及僵尸衣着、手脚和护具细节。
- 保留战斗状态驱动的摇摆、眨眼、射击回弹、啃咬、吞咽、撑杆跳、巨人砸击与投掷动画，以及坚果开裂、护具破损、断臂掉头、冰冻、灰烬和压扁效果。
- 新增 `src/art/paths.ts`，缓存 `Path2D` 轮廓并逐帧处理颜色，让不同尺寸的角色共用几何路径，同时保留受击与冰冻着色。
- 战场掉落的手臂与护具改为调用角色绘制函数，卷心菜弹丸复用植物美术中的球体绘制，统一角色与战斗特效的外观。

## 种子卡与图鉴

- 土豆地雷种子卡使用已就绪造型，调整火炬树桩、三线射手和巨型坚果的图标尺寸或位置。
- 僵尸图鉴列表由头像改为完整角色预览，按巨人、旗帜、小鬼、路障等体型分别调整比例与位置。

## 封面与构建

- 新增 `tools/build-cover.mjs`，在游戏构建时调用实际的植物和僵尸绘制函数，将向日葵、豌豆射手与普通僵尸导出为游戏厅 SVG 封面。
- 封面使用原生矢量路径，不内嵌截图或请求外部素材；重新构建时同步生成 `public/games/garden-guard/cover.svg`。
- 重新生成并保留 `.build/debug/`、sourcemap、压缩文件、构建元数据、`output/garden-guard.html` 与 `public/` 中的游戏产物，再构建站点并同步到 `docs/`。

## 文档与版本

- 更新根 README、游戏 README、更新日志索引及未发布记录，补充角色绘制、路径缓存、封面生成和美术参考说明。
- 将 `package.json` 与锁文件中的项目版本统一为 `0.1.7`。

## 验证

- `npm run game:garden`：独立 TypeScript 检查、单文件 HTML 和 SVG 封面构建通过；HTML 大小约 126 KB。
- `npm run build`：Vue / TypeScript 检查及 Vite 生产构建通过；发布前统一入口 HTML 的换行符，38 个发布文件与 `dist/` 逐一进行 SHA256 比对一致，本地 HTTP 访问均返回 200。
- 浏览器检查：18 张植物种子卡的角色没有超出图标区域；僵尸图鉴、战斗演示与站点内嵌游戏加载无运行时异常；390 像素宽移动端没有横向溢出。
- `output/`、`public/`、`dist/` 与 `docs/` 中的游戏 HTML 内容一致，三个站点目录中的 SVG 封面内容一致；封面 XML 解析通过且不包含图片节点。
- 构建脚本与压缩 JavaScript 语法、项目版本号、14 个本地 Markdown 链接、Git 差异空白检查及域名配置保留检查通过。
