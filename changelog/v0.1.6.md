# v0.1.6 · Yumo 改版与游戏体验

- 日期：2026-10-09
- 版本：0.1.6
- 对比基线：`808f05b`（v0.1.5 发布提交）
- 发布目录：`docs/`（GitHub Pages），保留 `CNAME` 自定义域名配置和 `music-api.md`。

站点由 Nocturne 更新为 Yumo，统一首页、随笔、音乐、工具、实验与游戏厅的视觉，并新增第三款游戏《瓜体实验室》。本记录覆盖基线之后的源码、静态资源、游戏构建产物与文档变更。

## 站点与随笔

- 更新站点品牌、包名、页面标题、导航文案与页脚；补充页面描述、主题色和 SVG favicon，移除 Google Fonts 外部字体引用。
- 重做首页：增加 `BrandCanvas` 彩色毛玻璃品牌海报、四个模块入口、最新随笔和个人介绍。
- 更新浅色背景、玻璃卡片、按钮、布局与响应式样式，照顾移动端排版与减少动态效果的系统偏好。
- 更新随笔列表、文章卡片装饰封面和详情页标题，标签筛选增加选中状态的无障碍标记。

## Yumo FM

- 重做侧栏、发现页、搜索页、收藏页、播放页与底部播放器，增加 `TurntableArt` 唱片机组件和 `MusicIcon` SVG 图标组件。
- 为五个主题歌单、三个精选合集增加本地 SVG 封面，不再用搜索到的歌曲封面覆盖主题图。
- 增加发现页加载骨架、专辑空状态、收藏空状态与返回发现页入口，优化移动端导航和播放器布局。
- 歌词改为可点击按钮，点击后跳到对应播放时间；补充播放进度、音量、收藏、循环和搜索等控件的无障碍标签与状态。
- 曲目封面加载失败时显示占位图，封面地址更新后可重新加载。
- 收藏与最近播放继续使用原有本地存储键，保留既有浏览器数据。

## 工具与实验

- 原工具占位页改为「灵感工作台」：提供 JSON 格式化、压缩和语法检查，UTF-8 Base64 编解码，以及配色切换、色值和结果复制。
- 工具输入在当前浏览器处理；增加错误提示、剪贴板不可用提示和输入长度限制。
- AquaInkGL 实验页增加注入色彩、暂停 / 继续、显示 / 隐藏介绍、全屏操作与状态提示。

## 游戏厅与公共外壳

- 游戏列表增加全部 / 动作 / 策略 / 物理筛选、数量展示与新的游戏封面卡片。
- 游戏详情重新整理操作说明与介绍，增加其他游戏的推荐入口。
- `GameFrame` 增加游戏编号、名称、类型与配色，支持整个外壳全屏、退出全屏和失败提示。
- 新增 `src/styles/arcade.css`，集中处理游戏外壳、工具栏、说明、推荐卡片和触屏布局。
- 三款游戏使用本地 SVG 封面。

## 《烬灯行》

- 更新场景配色、标题画面、灯笼视觉、状态面板、强化选择与结算画面。
- 键盘输入避开按钮、链接及表单控件，保留工具栏和导航的原生键盘操作。
- 触屏按钮迁入 `GameFrame` 的 `controls` 插槽，独立显示在画面下方；移除横屏全屏下覆盖画面的定位规则。
- 调整窄屏按钮宽度和间距，避免方向键与动作键互相挤压或超出容器。

## 《花园保卫战》

- 更新标题页的植物展示、草坪和背景配色，以及种子卡片、按钮、HUD、选关、图鉴、设置和奖励界面的视觉。
- 同步保留调试 bundle、sourcemap、压缩文件、构建元数据、独立 HTML 与 `public/games/garden-guard/index.html`。

## 新增《瓜体实验室》

- 新增半流体水果合成游戏，接入游戏注册表与 `/games/melon-fluid`，提供独立打开入口。
- 十级水果从葡萄演化到西瓜；相同水果碰撞融合，支持果冻、半流体、果汁三种材质切换。
- 通过弹性轮廓、碰撞和面积约束模拟挤压与变形，支持容器倾斜和消耗能量搅动果池；融合和等待可恢复能量。
- 支持鼠标、键盘和触屏，提供暂停、声音开关、操作说明、重开确认与本地最高分记录。
- 游戏静态文件位于 `public/games/melon-fluid/`，Vue 组件通过校验消息来源的高度通知调整 iframe 高度。
- 概念与交互参考 [半流体西瓜游戏](https://melon-game.jack-514.chatgpt.site/)，站内版本为独立实现。

## 文档与仓库

- 更新根 README 的品牌、功能、游戏列表、目录结构与游戏接入约定；未发布记录归档为本版本日志。
- 将 `package.json` 与锁文件中的项目版本统一为 `0.1.6`，重新构建并同步到 `docs/`，清理旧的哈希资源文件。
- 移除旧 `lumina-sonic-player` 仓库技能文件与对应代理配置。
